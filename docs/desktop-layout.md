# 阅读与交互布局

Codex Monitor 以会话正文为主。浅色和深色共用黑白灰层级，绿色、黄色、红色只表达运行状态、提醒和错误；正文链接保留可辨认的颜色与下划线。正文用 16px，宽屏用 17px，代码 14px，常用控件 14px、元信息 12px。

## 视口适配

| CSS 视口宽度 | 默认详情布局 |
| --- | --- |
| ≤760px | 单列阅读。顶栏底色延伸至 iOS 顶部安全区，48px 高的操作行避开刘海与系统状态栏。标题栏保留目录与更多操作，底部右侧打开跨工作空间的运行中会话。常用图标按钮尺寸为 44px，底部导航考虑 iOS 安全区，回车换行、点发送按钮提交。 |
| 761–1279px | 64px 导航栏，主区优先留给对话，会话列表按需打开为抽屉。 |
| 1280–1799px | 会话列表默认并排，实际宽度随视口在 256–320px 间变化；阅读与输入列居中，外宽最多 56rem。 |
| ≥1800px | 会话列表保留，阅读与输入列外宽最多 60rem，避免正文随 2K 显示器拉得过长。 |

布局按浏览器 CSS 视口，而不是设备物理分辨率选择。桌面低矮窗口压缩标题区和输入区，不缩小正文。代码和表格在自身容器内滚动。

## 常用流程

- 桌面顶栏可折叠导航和切换会话列表。面板切换保留草稿和附件。手动布局偏好保存在浏览器，“恢复自动布局”清除偏好。
- 任务动态按待处理、运行中、最近结束组织。宽屏首页双列；笔记本窄窗口与手机按优先级单列。历史搜索位于“全部会话”，CPU 与内存在“管理工作空间”中。
- 会话列表默认显示全部工作空间，可以按机器筛选；每条记录显示所属空间。详情旁的列表也可清除项目和状态筛选，不会切走当前会话。
- 桌面目录在阅读区左侧，悬停预览、点选定位，键盘可上下选择与 Enter 定位。手机在标题栏打开目录，定位后自动关闭。
- 标题栏只显示标题、来源、状态和运行计时。「更多会话操作 → 会话信息」查看完整标题、项目路径、模型、上下文和用量。正文不另设搜索框。
- 待答复卡片只显示简短摘要；打开问题可阅读 Markdown 正文和选项。较宽的代码与表格在自己的区域内横向滚动。
- 发送设置入口显示本条消息已选择的模型、思考级别或桌面通道。目标与上下文压缩排在快捷操作顶部，提示词依然可以先填入再编辑。
- 输入框下方、发送键旁的圆环显示最近一次模型调用的上下文占比。悬停或点按可查看已用 token 和窗口上限；虚线表示暂无可计算的占比。

## 回归验证

当前 [浏览器 E2E](e2e.md) 覆盖工作空间间草稿隔离、手机触控导航和横向边界。调整桌面多档宽度、任务入口或 Safari 安全区时，按本页布局约定补做对应尺寸及真机检查。
