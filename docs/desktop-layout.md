# 阅读与交互布局

Codex Monitor 以会话正文为主。浅色和深色共用黑白灰层级，绿色、黄色、红色只表达运行状态、提醒和错误；正文链接保留可辨认的颜色与下划线。正文用 16px，宽屏用 17px，代码 14px，常用控件 14px、元信息 12px。

## 视口适配

| CSS 视口宽度 | 默认详情布局 |
| --- | --- |
| ≤760px | 单列阅读。任务动态入口在顶部导航，目录入口与内容搜索同区，两者不遮挡正文。常用图标按钮尺寸为 44px，输入框考虑 iOS 底部安全区，回车换行、点发送按钮提交。 |
| 761–1279px | 64px 导航栏，主区优先留给对话，会话列表按需打开为抽屉。 |
| 1280–1799px | 会话列表默认并排，实际宽度随视口在 256–320px 间变化；阅读与输入列居中，外宽最多 56rem。 |
| ≥1800px | 会话列表保留，阅读与输入列外宽最多 60rem，避免正文随 2K 显示器拉得过长。 |

布局按浏览器 CSS 视口，而不是设备物理分辨率选择。桌面低矮窗口压缩标题区和输入区，不缩小正文。代码和表格在自身容器内滚动。

## 常用流程

- 桌面顶栏可折叠导航、切换会话列表并进入专注模式。Esc 退出专注；面板切换保留草稿和附件。手动布局偏好保存在浏览器，“恢复自动布局”清除偏好。
- 任务动态按待处理、运行中、最近结束组织。宽屏首页双列；笔记本窄窗口与手机按优先级单列。历史搜索位于“全部会话”，CPU 与内存在“管理工作空间”中。
- 桌面目录在阅读区左侧，悬停预览、点选定位，键盘可上下选择与 Enter 定位。手机目录可从会话工具栏开关，定位后自动关闭。
- “详情”展开完整标题、项目路径、模型和用量。内容搜索显示匹配数与已加载范围，可继续加载更早记录；Esc 清除查询。
- 发送设置入口显示本条消息已选择的模型、思考级别或桌面通道。目标与上下文压缩排在快捷操作顶部，提示词依然可以先填入再编辑。

## 回归验证

`tests/e2e/desktop-layout.spec.ts` 覆盖六档桌面窗口与 440px 手机视口，验证阅读宽度、触控入口、面板切换、草稿保留和横向边界。`tests/e2e/app.spec.ts` 覆盖明暗主题下的目录、搜索、快捷操作和发送设置。
