# PC 全局适配方案

目标：将聊天阅读和输入作为详情页的主要区域，按可用空间安排导航、会话列表和目录。统一适配笔记本、普通显示器、宽屏、分屏窗口和浏览器缩放后的 CSS 视口。

## 空间分配

原界面在 1920px 宽屏时同时保留约 245px 项目导航、335px 会话列表和 240px 目录；时间线本身又限宽 900px。顶部多层信息和底部多行输入工具继续挤压聊天高度。仅扩大一个容器无法解决这些占用。

新布局由应用框架、辅助面板、阅读区域、输入区域四部分共同约束：

| 区域     | 规则                                                                                                                                            |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 全局导航 | 完整宽度 216px；详情页默认收成 64px 图标栏。总览和统计页在宽度足够时展开。图标保留标题提示和可访问名称，项目仍可直接点击。                      |
| 会话列表 | 1280px 起默认并排显示，宽度用 `clamp(240px, 18vw, 296px)`；可随时收起。窄窗口使用 300px 抽屉，打开时不改变聊天区宽度，选中会话后关闭。          |
| 对话目录 | 桌面默认显示正文左侧的短横线导航，不占用独立侧栏；悬停预览该轮提问和回复，点击定位，滚动时高亮当前轮次。顶部目录按钮可开关导航。                |
| 正文     | 使用剩余空间；时间线最大宽度 1280px，左右留白随窗口变化。宽屏居中保持可读性；代码和表格只在内容区域内滚动。PC 正文统一 14px，代码和表格 12px。  |
| 顶部     | 全局栏 48px，详情标题、状态摘要和内容搜索保持紧凑。状态、项目、上下文直接可见，空间充足时补充模型；完整路径、会话 ID 和用量详情通过“详情”展开。 |
| 输入     | 标题与常用操作共用一行，附件、模型选择、计数和发送共用底部一行。默认文本框 64px，可拖高；输入区最多占视口高度 42%，附件和反馈过多时独立滚动。   |

## 响应式规则

| CSS 视口宽度 | 默认详情布局                                                          |
| ------------ | --------------------------------------------------------------------- |
| ≤760px       | 手机布局；目录按需展开，点横线预览，再点卡片或同一横线定位。          |
| 761–1279px   | 64px 导航 + 主聊天区和左侧目录横线；会话列表使用抽屉。                |
| 1280–1799px  | 64px 导航 + 会话列表 + 主聊天区和左侧目录横线。                       |
| ≥1800px      | 64px 导航 + 会话列表 + 主聊天区和左侧目录横线；正文保持最大阅读宽度。 |

PC 视口高度 ≤800px 时，全局栏降为 44px，详情标题区 48px、摘要 32px、搜索栏 32px，输入框默认 48px。布局使用 `100dvh` 和可收缩的 flex 区域，不因页面最小高度产生整页滚动。

目录始终位于正文阅读区左侧，预览卡片限制在阅读区内。长目录可独立滚动，定位时自动加载尚未读取的历史；展开目录后，正在跟随最新消息的时间线仍保持在底部。键盘可用上下键切换提问、Enter 定位、Esc 关闭预览。

## 手动控制与状态

- 顶栏提供导航折叠、会话列表切换、专注模式和恢复自动布局。
- 专注模式隐藏导航、会话列表和目录；保留标题、搜索和输入。退出按钮或 Esc 恢复原面板选择。专注时点击目录按钮会退出专注并打开目录。
- 导航和宽屏会话列表的手动选择保存在当前浏览器，刷新后恢复。窄屏抽屉和专注模式只在当前界面生效。
- 恢复自动布局清除手动面板偏好，重新按当前尺寸分配空间。
- 在详情页非编辑区域按 `/`，自动展开会话列表并聚焦搜索。面板切换不卸载聊天时间线或输入组件，因此保留草稿、附件和已加载的记录。
- 所有桌面布局样式集中在 `src/styles/desktop-layout.css`，尺寸使用统一 CSS 变量；媒体查询监听位于共享 hook，浏览器偏好与交互状态由 `useDesktopLayout` 管理。

## 实测结果

以下记录此前 PC 布局调整的历史测量，当时目录仍在右侧停靠；当前横线目录已取消独立侧栏。测量使用同一套独立测试数据、相同窗口尺寸和 Edge 无头浏览器；消息宽度为 `.message-content` 容器宽度，聊天高度为 `.timeline-scroll` 高度。下表均为默认布局，未启用专注模式。

| 视口      | 消息宽度：原版 → 新版 | 聊天高度：原版 → 新版 |
| --------- | --------------------- | --------------------- |
| 1024×768  | 488 → 879px           | 168 → 456px           |
| 1280×720  | 417 → 895px           | 120 → 408px           |
| 1366×768  | 503 → 975px           | 168 → 456px           |
| 1440×900  | 577 → 1020px          | 287 → 540px           |
| 1920×960  | 767 → 1167px          | 342 → 600px           |
| 2560×1440 | 767 → 1167px          | 822 → 1080px          |

1920×960 下消息容器增宽约 52%，聊天高度增加约 75%。默认输入区从约 266px 压缩到 159px；高度较低的 PC 窗口为 135px。具体占用会随目标、附件、发送回执和错误提示变化，这些内容仍完整保留。

验证覆盖六档窗口、整页横纵溢出、面板偏好恢复、草稿保留、抽屉关闭、跨 PC/手机尺寸切换、目录预览与历史定位、专注模式退出及详情用量入口。目录另外覆盖长列表滚动、阅读位置高亮、键盘操作、手机触控和明暗主题。
